# LifeOS

> An AI-Powered Personal Life Operating System.

LifeOS is not a task manager, calendar, habit tracker, or note-taking app. It is an intelligent Chief of Staff that understands every aspect of your life and helps you make better decisions every day.

**The objective is not maximizing productivity. The objective is helping you build a meaningful, balanced, and successful life.**

---

## Philosophy

Everything in LifeOS answers one question:

> *"Does this genuinely reduce cognitive load and help the user make better life decisions?"*

Users spend very little time organizing data. The AI does the organizing. The AI infers instead of asking. The AI recommends instead of waiting. The AI explains every important decision.

## Quick Start

```bash
# Clone the repository
git clone <repo-url>
cd lifeos

# Install dependencies
npm install

# Start development server
npm run dev
```

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui |
| State Management | Zustand, TanStack Query |
| Forms | React Hook Form, Zod |
| Database | PostgreSQL (via Supabase) |
| ORM | Prisma / Drizzle |
| AI | OpenRouter (multi-model) |
| Auth | Supabase Auth |
| Storage | Supabase Storage |
